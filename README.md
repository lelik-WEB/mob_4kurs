ЗАДАНИЕ ВАРИАНТ2 Практическая работа01
Разработать мобильное приложение для получения и отображения списка рецептов. 
Для получения списка рецептов (recipes) использовать Fake API https://dummyjson.com/. 
Вывести полученный список рецептов, включая 
-название (name), 
-время приготовления (cookTimeMinutes) и 
-сложность (difficulty) рецепта.
